# Package index

## All functions

- [`animate_manifold()`](https://eblini.github.io/Pupilla/reference/animate_manifold.md)
  : Animate a 3D scatterplot (based on plot3D) through gifski
- [`bayesian_test()`](https://eblini.github.io/Pupilla/reference/bayesian_test.md)
  : Highlights and test the time-course of effects through bayes factors
- [`check_all_series()`](https://eblini.github.io/Pupilla/reference/check_all_series.md)
  : Convenience function to check series across IDs and Trials, and save
  a plot in the current path
- [`check_series()`](https://eblini.github.io/Pupilla/reference/check_series.md)
  : Plots two time series against each other
- [`consolidate_signal()`](https://eblini.github.io/Pupilla/reference/consolidate_signal.md)
  : Consolidate pupil data according to different heuristics
- [`copy_variable()`](https://eblini.github.io/Pupilla/reference/copy_variable.md)
  : copy a variable from one data.frame to another of different length
  given ID and Trial constraints
- [`decode_signal()`](https://eblini.github.io/Pupilla/reference/decode_signal.md)
  : Highlights and test the time-course of effects through
  crossvalidation
- [`decode_signal_g()`](https://eblini.github.io/Pupilla/reference/decode_signal_g.md)
  : Highlights and test the time-course of effects through
  crossvalidation (uses glmer)
- [`detect_change()`](https://eblini.github.io/Pupilla/reference/detect_change.md)
  : Detect a change in a column, and returns an incremental counter
- [`downsample_time()`](https://eblini.github.io/Pupilla/reference/downsample_time.md)
  : Recode a Time variable to a different granularity
- [`interpolate()`](https://eblini.github.io/Pupilla/reference/interpolate.md)
  : Linearly interpolate signal provided quality checks are met, else
  only returns NAs
- [`interpret_bayes()`](https://eblini.github.io/Pupilla/reference/interpret_bayes.md)
  : Interprets easily the results of 'bayesian_test'
- [`interpret_lmem()`](https://eblini.github.io/Pupilla/reference/interpret_lmem.md)
  : Interprets easily the results of 'lmem_test'
- [`lmem_test()`](https://eblini.github.io/Pupilla/reference/lmem_test.md)
  : Highlights and test the time-course of effects through mixed-effects
  models
- [`plot_fingerprints()`](https://eblini.github.io/Pupilla/reference/plot_fingerprints.md)
  : Plot all (three) fingerprints of reduced time-series
- [`plot_lmem()`](https://eblini.github.io/Pupilla/reference/plot_lmem.md)
  : takes an LMEM object and plots the results
- [`plot_loadings()`](https://eblini.github.io/Pupilla/reference/plot_loadings.md)
  : Plot loadings of a reduced time-series
- [`plot_manifold()`](https://eblini.github.io/Pupilla/reference/plot_manifold.md)
  : Plot a 3D scatterplot (based on plot3D) based on a reduce_rPCA
  object
- [`pp_options()`](https://eblini.github.io/Pupilla/reference/pp_options.md)
  : Set or get options for Pupilla's preprocessing parameters
- [`predict_feature()`](https://eblini.github.io/Pupilla/reference/predict_feature.md)
  : Predicts features' scores from a model
- [`pre_process()`](https://eblini.github.io/Pupilla/reference/pre_process.md)
  : A convenience function to preprocess pupillometry data
- [`read_eyelink()`](https://eblini.github.io/Pupilla/reference/read_eyelink.md)
  : Reads and imports eyelink eye-tracking and behavioral data
- [`read_TOBII()`](https://eblini.github.io/Pupilla/reference/read_TOBII.md)
  : Reads and imports TOBII eye-tracking and behavioral data
- [`reduce_ICA()`](https://eblini.github.io/Pupilla/reference/reduce_ICA.md)
  : Reduce time-series to few Independent Components
- [`reduce_PCA()`](https://eblini.github.io/Pupilla/reference/reduce_PCA.md)
  : Reduce time-series to few Principal Components
- [`reduce_rPCA()`](https://eblini.github.io/Pupilla/reference/reduce_rPCA.md)
  : Reduce time-series to few (rotated) Principal Components
- [`smooth_vector()`](https://eblini.github.io/Pupilla/reference/smooth_vector.md)
  : Smooth a time series through cubic splines
- [`speed_clean()`](https://eblini.github.io/Pupilla/reference/speed_clean.md)
  : Help identifying artifacts with a speed-based criterion
- [`trim_loadings()`](https://eblini.github.io/Pupilla/reference/trim_loadings.md)
  : Trim rPCA loadings according to heuristics and append them to the
  original object
